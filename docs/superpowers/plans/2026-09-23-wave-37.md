**Produces:** `FoodSettings.cookMin?: { weekday?: number; weekend?: number }`; `DayOptions.maxCookMin?: number`; в `generateDay` основные приёмы фильтруются `(time_min ?? 0) <= maxCookMin`, если после фильтра пусто — полный список. `cookLimitFor(food, iso): number|undefined` в `src/ui/dayOpts.ts` (сб/вс — weekend).
- [ ] тест: maxCookMin 30 → все основные ≤30 мин при наличии; при отсутствии — день не пустой.
### C2 «Сегодня не готовлю»
**Produces:** `StoredState.noCookDays?: string[]`; в этот день `maxCookMin = 10` на обоих экранах.
### C3 День подстраивается под факт
**Produces:** `rebalance(day: Day, eaten: DayEaten|undefined): { day: Day; noteRU?: string }` — неотмеченные приёмы позже последнего отмеченного получают порцию ×k, k = (план − съедено) / план_остатка, k ∈ [0.7, 1.3], применяется при |k−1| ≥ 0.1.
- [ ] тесты: плотный обед → ужин меньше и note; нет отметок → без изменений; k режется до 0.7.
