# edim & spim 2.0 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (выполняется в этой же сессии). Шаги — чекбоксы.

**Goal:** Новый интерфейс «Небо» (спека `docs/superpowers/specs/2026-10-06-edimspim-2.0-design.md`) поверх существующей логики, с переключением целиком и удалением старых экранов.

**Architecture:** Состояние и все обработчики выносятся из `App.tsx` в хук `useAppState`. Новые экраны живут в `src/ui2/` (свой `sky.css`), переиспользуют формы и шторки из `src/ui/` (Sheet, EatSheet, MealIngredients, SwipeRow, Coach, QuickStart, Onboarding, FoodSetup, Catalog, Fridge). Пока идёт работа, 2.0 включается флагом `?v2`; в конце `main.tsx` рендерит только 2.0, старые экраны удаляются. Новая логика — чистые функции в `src/` с тестами vitest.

**Tech Stack:** React 19, TypeScript, Vite PWA, vitest; Figma-макеты «2.0 «Небо» — экраны».

## Global Constraints
- Бесплатно, без Apple Developer Program; PWA, проверка только под iPhone (375×812 и 393×852).
- Вибрации на iPhone нет — отклик анимацией; `haptics.ts` остаётся для Android.
- 5 размеров шрифта: 34 / 22 / 17 / 15 / 13. Один тип карточки (стекло 72–78%, радиус 20). Карточка в карточке запрещена.
- Ни одного серого абзаца-пояснения в потоке экрана; «почему» — только шторкой.
- Критерий успеха: «Сутки» — до первого действия ≤ 40 слов и 0 прокрутки; «Еда» ≤ 2 экранов.
- Данные совместимы: `StoredState` получает только необязательные поля; старые копии открываются.
- Честная рамка: оценки со «≈», без баллов и красного, «наблюдение, а не вывод».
- Слова: таблица §8 спеки («Ложишься в одно время?», «Время подъёма», «Свободный день», «Вес стоит», «клетчатка»).
- Работа в ветке `v2` прямо в `app/` (без отдельных папок); выкатка — один раз в конце.
- Каждая задача: `npm run typecheck && npm test && npm run build` зелёные → коммит.

## Фаза 2 — новая логика (TDD)

### Task 3: Слово дня
**Files:** Create `src/dayWord.ts`, `tests/day-word.test.ts`.
**Produces:** `dayWord(i: { nowMin: number; logged: boolean; rough: boolean; mode: DayMode; cheat: boolean; dinnerMin?: number; dinnerMarked: boolean; bedMin: number; sleptMin?: number; wokeHM: string }): { word: string; sub: string; phase: "morning" | "day" | "evening" }`.
Правила (порядок важен): читмил → «Свободный день»; ночь не отмечена и `nowMin < 11:00` → «Доброе утро» / «встал в HH:MM»; (время ужина прошло или ужин отмечен) и до отбоя < 3 ч → «Пора закругляться» / «спать в HH:MM · через Ч ч ММ», phase evening; плохая ночь → «Лёгкий день» / «ночь Ч ч ММ · план проще, калории те же»; crunch → «Долгий день»; recovery → «День отдыха»; иначе «Обычный день».
- [ ] тесты на каждую строку таблицы и на порядок (читмил сильнее вечера; вечер сильнее «лёгкого»)

### Task 4: «Вчера было?» и личный эффект
**Files:** Modify `src/ui/storage.ts` (`StoredState.yesterday?: Record<date, Yesterday>` — отдельно от отметки ночи, чтобы ответить можно было до неё); Create `src/effects.ts`, `tests/effects.test.ts`.
**Produces:** `personalEffects(history: DayLog[], yesterday: Record<string, Yesterday>, targetSleepMin: number): Effect[]`, `type Yesterday = { lateDinner?; lateCaffeine?; alcohol? }`; действие `setYesterday(date, key, value)`, `type Effect = { factor: "lateDinner" | "lateCaffeine" | "alcohol"; yes: number; no: number; ready: boolean; qualityDiff?: number; sleepDiffMin?: number; textRU?: string }`.
Ответ «вчера было» в записи дня D относится к ночи перед D. Сравнение: средняя оценка и длительность (где отбой известен) после «да» против «нет». `ready` при ≥ 5 и ≥ 5. Текст — наблюдение: «после поздних ужинов спишь в среднем на 25 мин меньше» / «оценка сна ниже на 0.8»; разница < 10 мин и < 0.3 балла → «заметной разницы нет».
- [ ] тесты: не готово при 4/5; готово при 5/5 с разницей; без разницы — «заметной разницы нет»; алкоголь берётся из `hadAlcohol`

### Task 5: Серия с заморозками и цифра на иконке
**Files:** Create `src/streak2.ts`, `tests/streak2.test.ts`.
**Produces:** `streakWithFreezes(markedDates: string[], protectedDates: string[], today: string, freezesPerWeek = 2): number` — подряд идущие дни назад от сегодня (сегодня без отметки не рвёт); день с отметкой или «защищённый» (читмил) засчитан; пропуск гасится заморозкой, не больше 2 за календарную неделю. `unmarkedToday(day: Day | null, eaten?: DayEaten): number`.
- [ ] тесты: 5 дней подряд = 5; пропуск 1 день внутри = серия продолжается; 3 пропуска за неделю = рвётся; читмил не рвёт
